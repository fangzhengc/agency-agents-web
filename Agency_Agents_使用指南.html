项目简介

Agency Agents 中文版 是 agency-agents 的中文社区版，在完整翻译上游的基础上，新增了 50 个中国市场原创智能体。

核心特点

特性 说明
🤖 智能体数量 215 个
🏢 部门覆盖 18 个
🛠️ 支持工具 17 种（Claude Code / Cursor / Copilot 等）
🇨🇳 中国原创 50 个（小红书/抖音/微信/飞书/钉钉等）

与普通提示词的区别

普通提示词 Agency Agents
"你是一个前端开发者" 定义了开发者怎么思考、怎么做事、交付什么
通用模板 专业流程 + 可交付成果
无角色区分 每个智能体有独立人设和工作方式

安装过程

前置要求

依赖 最低版本 说明
Git 2.0+ 用于克隆仓库
Bash 4.0+ 运行安装脚本
Node.js 18+ OpenClaw 用户需要（可选）

第一步：克隆仓库

# 克隆中文版仓库
git clone https://github.com/jnMetaCode/agency-agents-zh.git

# 进入项目目录
cd agency-agents-zh

第二步：自动检测并安装

# 自动检测已安装的 AI 工具，一键安装
./scripts/install.sh

脚本会自动扫描你系统上已安装的 AI 工具，然后将智能体安装到对应目录。

第三步：指定工具安装（可选）

如果你想明确指定安装到某个工具：

# Claude Code
./scripts/install.sh --tool claude-code

# Cursor
./scripts/install.sh --tool cursor

# GitHub Copilot
./scripts/install.sh --tool copilot

# Hermes Agent
./scripts/install.sh --tool hermes

# OpenClaw（推荐，社区用户最多）
./scripts/install.sh --tool openclaw

# 其他支持的工具
./scripts/install.sh --tool aider
./scripts/install.sh --tool windsurf
./scripts/install.sh --tool codex
./scripts/install.sh --tool gemini-cli
./scripts/install.sh --tool qwen
./scripts/install.sh --tool opencode
./scripts/install.sh --tool kiro
./scripts/install.sh --tool trae
./scripts/install.sh --tool deerflow
./scripts/install.sh --tool workbuddy
./scripts/install.sh --tool qoder

第四步：格式转换（非 Claude Code/Copilot 用户）

大部分工具需要先将 Markdown 格式转换为目标工具的格式：

# 先转换格式
./scripts/convert.sh --tool <工具名>

# 再安装
./scripts/install.sh --tool <工具名>

如何使用

方式一：自然语言激活（推荐）

在与 Hermes Agent 对话时，直接告诉它激活某个角色：

"激活前端开发者模式，帮我构建一个 React 登录组件"

"切换到安全工程师角色，审查这段代码的安全性"

"用小红书运营专家的身份，帮我写一篇种草笔记"

方式二：参考智能体能力

每个智能体文件包含： - 身份定义：角色背景、专业领域 - 核心能力：具体能做什么 - 工作流程：怎么做事 - 交付物：会输出什么

你可以浏览智能体文件，参考其专业流程。

角色恢复与切换

激活角色后，可以随时通过以下方式恢复或切换：

退出角色（恢复默认模式）

"退出前端开发者模式，恢复正常助手"

"切换回默认模式"

"结束小红书运营专家角色"

开始新对话

  • Hermes / Claude Code：直接开新会话，角色自动重置
  • Cursor / Copilot：新开 Chat 窗口即可

切换到其他角色

"现在切换到后端架构师角色，帮我设计 API"

自动从当前角色切换到新角色，无需先退出。

原理说明

状态 说明
激活角色 AI 加载了角色的 SKILL.md，按专业流程工作
退出角色 AI 回到通用助手模式，不再受角色约束
切换角色 直接加载新角色的 SKILL.md，覆盖当前角色

本质上是 prompt 上下文的切换，随时可以用自然语言控制。

高级用法

1. 组合多个角色

"用产品经理写需求，然后让前端开发者实现，最后让测试工程师验证"

2. 参考专业流程

每个智能体的 .md 文件定义了完整的工作流程，你可以： - 直接复制流程到其他工具使用 - 根据项目需求调整流程 - 作为团队协作的标准模板

3. 查看智能体详情

# 查看某个智能体的完整定义
cat ~/.hermes/skills/engineering/engineering-frontend-developer.md

# 搜索特定能力的智能体
grep -r "React" ~/.hermes/skills/ --include="*.md"

常见问题

Q: 这些智能体和普通提示词有什么区别？

A: 普通提示词只是告诉 AI "你是一个专家"，而这里的每个智能体都定义了： - 专业身份和背景 - 具体的工作流程 - 交付物的标准 - 成功指标

Q: 可以同时激活多个智能体吗？

A: 可以！你可以让多个角色协作完成复杂任务，比如"产品经理写需求，前端实现，测试验证"。

Q: 如何查看所有可用的智能体？

A: 

# 查看所有智能体文件
find ~/.hermes/skills -name "*.md" -type f | head -50

# 查看某个部门的智能体
ls ~/.hermes/skills/marketing/

Q: 中国市场的智能体有哪些？

A: 专门为中国市场设计的智能体包括： - 小红书运营专家 - 抖音策略师 - B站内容策略师 - 微信公众号运营 - 微博策略师 - 中国电商运营 - 快手策略师 - 私域运营专家 - 飞书集成开发者 - 微信小程序开发者 - 等等...
