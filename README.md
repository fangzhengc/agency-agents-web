# Agency Agents 中文版 — Web 浏览页面

> 215 个即插即用的 AI 专家角色，覆盖 18 个部门

## 在线访问

🔗 [https://fangzhengc.github.io/agency-agents-web/](https://fangzhengc.github.io/agency-agents-web/)

## 功能

- 🔍 搜索：按名称、描述、能力搜索
- 🏷️ 部门筛选：18 个部门标签一键过滤
- 📋 点击卡片查看详情 + 一键复制激活指令
- 📱 响应式设计，手机/电脑都能用
